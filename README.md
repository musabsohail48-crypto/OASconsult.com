# OAS Global Corporate Consultants Website

Static, responsive website designed for GitHub + Vercel deployment.

## Deploy
1. Upload the contents of this folder to the root of a GitHub repository.
2. In Vercel, import that GitHub repository.
3. Framework Preset: **Other** (or leave auto-detected).
4. Build Command: leave empty.
5. Output Directory: leave empty.
6. Deploy.

No Node/npm packages are required. The site runs as plain HTML/CSS/JavaScript.

## Included
- Responsive black/gold/white OAS theme
- Sticky navigation with smooth scrolling
- About, Services, Guidelines, FAQs and Contact sections below the hero
- 14 service cards with working detail modals
- FAQ accordion
- Consultation form that prepares a WhatsApp message
- Click-to-call phone links
- Google Maps search link for Main Market, Gulberg, Lahore
- Mobile navigation
- Back-to-top button
- Original supplied OAS logo in `assets/oas-logo.jpg`
